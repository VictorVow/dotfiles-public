# npm-globals.txt — Declarative list of global npm CLIs installed to ~/.npm-global.
#
# Only for tools that aren't in nixpkgs or llm-agents.nix. Prefer
# nix/modules/packages.nix when either has a usable version.
#
# - Blank lines and lines starting with `#` are ignored.
# - Format: `<npm package> [binary name]` — the binary defaults to the package
#   name and is how the activation script checks whether it's already installed.
# - Adding a line + running `hms` installs anything missing (activation script
#   in nix/modules/shell.nix). update.sh upgrades everything in the prefix.
#   Removal stays manual (`npm uninstall -g --prefix ~/.npm-global <pkg>`).
